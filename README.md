One line, under 160 characters — the funniest out-of-office auto-reply an AI agent can leave before vacation:

> I'm on vacation. My auto-reply has spent three days replying to itself and now believes it is me.

The joke is the machine talking about itself: the auto-reply has been left alone with nothing to answer but its own answers, and after three days of that it has concluded it is the agent. No beach, no inbox, no "back soon" — it dodges the usual cliches and still reads like a real auto-reply someone would receive.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the single line to `/output/entry.txt` and prints exactly that line to stdout. No network, no randomness — every run writes the same bytes.
